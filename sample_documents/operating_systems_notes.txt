OPERATING SYSTEMS (CS301) - COMPREHENSIVE LECTURE NOTES

UNIT 1: PROCESSES AND THREADS
A process is an active program in execution. It includes the program counter, process stack, data section, and heap.
The Process Control Block (PCB) is a data structure used by the OS to manage process information, including process state, PID, CPU registers, and scheduling information.
Process states include: New, Ready, Running, Waiting (Blocked), and Terminated.
A thread is the smallest unit of CPU utilization, consisting of a thread ID, program counter, register set, and a stack. Threads within the same process share code, data sections, and OS resources like open files.

UNIT 2: CPU SCHEDULING ALGORITHMS
1. First-Come, First-Served (FCFS): Non-preemptive algorithm that suffers from the convoy effect.
2. Shortest-Job-First (SJF): Provably optimal in minimizing average turnaround and waiting time. Can be preemptive (Shortest Remaining Time First - SRTF).
3. Round Robin (RR): Designed for time-sharing systems. Each process gets a small unit of CPU time (time quantum q).
4. Priority Scheduling: Each process is assigned a priority. A major issue is starvation, solved using aging.

UNIT 3: SYNCHRONIZATION AND DEADLOCKS
The Critical Section Problem requires three criteria:
1. Mutual Exclusion: If process Pi is executing in its critical section, no other processes can be executing in their critical sections.
2. Progress: If no process is executing in its critical section and there exist processes that wish to enter, selection cannot be postponed indefinitely.
3. Bounded Waiting: A bound exists on the number of times other processes are allowed to enter their critical sections after a process has requested entry.

Semaphores:
A semaphore S is an integer variable accessed only through two standard atomic operations: wait() and signal().
wait(S) { while (S <= 0); S--; }
signal(S) { S++; }
Binary semaphores take values 0 and 1, functioning as mutex locks. Counting semaphores range across unrestricted non-negative values.

Deadlock Coffman Conditions:
Deadlocks can arise if four conditions hold simultaneously:
1. Mutual Exclusion
2. Hold and Wait
3. No Preemption
4. Circular Wait

UNIT 4: MEMORY MANAGEMENT AND VIRTUAL MEMORY
Logical versus physical address spaces: Logical address is generated by the CPU; physical address is seen by the memory unit. The Memory Management Unit (MMU) handles run-time translation.
Paging: Memory management scheme that avoids external fragmentation. Logical address consists of page number (p) and page offset (d).
Virtual Memory: Allows execution of processes not completely in physical memory.
Demand Paging: Pages are loaded only when they are demanded during program execution.
Page Replacement Algorithms:
- FIFO (First-In, First-Out): Suffers from Belady's Anomaly (more frames can lead to more page faults).
- Optimal Algorithm: Replaces the page that will not be used for the longest period of time (used as a benchmark).
- LRU (Least Recently Used): Replaces the page that has not been used for the longest period of time.
Thrashing: High paging activity where a process spends more time paging than executing.
